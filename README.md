# Business Insights 360 – Power BI Dashboard

## Overview
This is a multi-page Power BI dashboard built to analyze Finance, Sales, Marketing and Supply Chain performance.

## Tools Used
- Power BI
- DAX
- Power Query
- Data Modeling

## Features
- Executive dashboard
- P&L analysis
- Net sales and profit tracking
- Forecast accuracy
- Region & product analysis
